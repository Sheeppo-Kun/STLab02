# STLab02 – Test Case Execution

## 1. Giới thiệu
Đây là bài thực hành STLab02 – Test Case Execution, sử dụng Python và Google Colab để thực hiện kiểm thử tự động cho hệ thống EduCommerce.

## 2. Mục tiêu
- Phân tích các yêu cầu kiểm thử (Requirement).
- Xây dựng Test Condition, Test Scenario và Test Case.
- Thực thi kiểm thử tự động bằng Python.
- Đối chiếu kết quả thực tế với kết quả mong đợi.
- Tạo báo cáo và ma trận truy vết kiểm thử (Traceability Matrix).

## 3. Các yêu cầu được lựa chọn
- REQ-01: Catalog
- REQ-02: Cart
- REQ-03: Pricing
- REQ-09: Shipping
- REQ-10: Payment

## 4. Cấu trúc dự án
- `ecommerce_app.py`: Mã nguồn ứng dụng EduCommerce.
- `test_runner.py`: Chương trình thực thi kiểm thử tự động.
- `test_cases.csv`: Danh sách các Test Case.
- `test_execution.csv`: Kết quả thực thi kiểm thử.
- `traceability_matrix.csv`: Ma trận truy vết kiểm thử.
- `reports/`: Các báo cáo kiểm thử được xuất ra.
- `STLab02_EduCommerce.ipynb`: Notebook thực hiện trên Google Colab.

## 5. Kết quả kiểm thử
- Tổng số Test Case: 15
- PASS: 15
- FAIL: 0
- BLOCKED: 0
- Tỷ lệ PASS: 100%

## 6. Công cụ sử dụng
- Python
- Google Colab
- GitHub

## 7. Báo cáo
Các báo cáo kiểm thử được lưu trong thư mục `reports/`, bao gồm CSV, Excel và HTML Dashboard.
